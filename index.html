📖 DEPLOYMENT GUIDE
Backend (Render.com):
1. Push main.py to GitHub
2. Create new Web Service on Render
3. Build command: pip install fastapi uvicorn aiohttp pyjwt
4. Start command: python main.py
5. Add env vars: TMDB_API_KEY, OWNER_USERNAME, OWNER_PASSWORD, SECRET_KEY

Frontend (Vercel.com):
1. Upload index.html to GitHub
2. Import project on Vercel
3. Deploy as static site
4. Update API_BASE in this file to your Render URL
